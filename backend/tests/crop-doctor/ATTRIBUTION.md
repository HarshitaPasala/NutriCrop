# Crop Doctor mock test images

These three photos are copied from `Crop_Disease_Images/images/` in the repository's Crop Disease Expert Annotations dataset. The dataset is licensed under **CC BY 4.0** (see `Crop_Disease_Images/README.md`). Attribution: Digital Green / Farmer.Chat, Crop Disease Expert Annotations dataset, CC BY 4.0. The source annotations identify `00437.jpg` as Healthy (Onion), `00849.jpg` as Tomato Leaf Curl, and `00181.jpg` as Paddy Leaf Blast.

The mock service recognizes only these exact bytes by SHA-256. This gives developers repeatable demo cases without presenting a crop hint or filename as visual diagnosis.
